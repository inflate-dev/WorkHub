# WorkHub (MVP)

トップに3つのタブ(顧客窓口 / 社内AI / 社内コミュニケーション)を持つMVPです。

- **顧客窓口**(`/` ・実装済み): 故障内容(便器の故障/給湯器の故障/水漏れ・給水関連の不調/その他・原因箇所不明)をプルダウンで選択→詳しい症状を選択→写真添付(任意)→「見積もり作成」ボタンでダミーの概算見積り(税込レンジ)を表示します。
- **社内AI**(`/ai` ・見た目のみ): 社内情報を参照するチャットボットのダミー画面です。
- **社内コミュニケーション**(`/communication` ・見た目のみ): 優先度が低いため「準備中」の説明のみです。

**現状の割り切り(MVP)**:
- バックエンド・DBはなく、すべてフロントエンドのダミーデータ・ダミー計算です(`src/lib/faults.ts`)。
- 見積金額は固定のダミーレンジで、OpenAI等のAPI連携はしていません。
- 写真添付はブラウザ内プレビューのみで、実際のアップロード・保存は行いません。
- 顧客からの申込みを受け取る社員向け管理画面は今回のスコープから外しています。

詳細な仕様の背景は [docs/01_仕様書.md](docs/01_仕様書.md) を参照してください(現在のUIとは仕様書の内容が一部異なります)。

## セットアップ

```bash
npm install
npm run dev
```

http://localhost:3000 を開いてください。
